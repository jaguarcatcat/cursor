# Парсер выдачи Google News

Скрипт снимает срез **Google News / Google Новости**, а не обычной органической выдачи Google.

## Что собирается

По каждому запросу:

- позиция в новостной выдаче;
- заголовок, СМИ, URL, домен, дата;
- сниппет **только если он есть в самой выдаче Google**; иначе пишется `сниппет Google недоступен`;
- тип результата (если его можно определить по карточке);
- комментарий о релевантности;
- отметка, если Google сгруппировал несколько публикаций в один сюжет.

Разные URL одного СМИ не сливаются. Удаляются только точные дубли одной страницы (после нормализации `http/https`, `www` и utm-меток).

## Запуск

```bash
python3 google_news_parser.py
```

Параметры по умолчанию:

- запросы: `лобов вадим университет синергия`, `лобов вадим синергия`, `лобов вадим`;
- регион/язык: `hl=ru`, `gl=RU`, `ceid=RU:ru`;
- глубина: первые 20 результатов.

Результаты пишутся в `output/`:

- `google_news_report.md`
- `google_news_results.json`
- `google_news_results.csv`

Разбор сохранённого HTML:

```bash
python3 google_news_parser.py --from-html tests/fixtures/sample_search.html --query "лобов вадим университет синергия"
```
