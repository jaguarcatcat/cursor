# Google News RU parser

`google_news_parser.py` сохраняет максимально близкий к серверной HTML-выдаче
Google News срез для региона Россия (`gl=RU`, `ceid=RU:ru`) и русского интерфейса
(`hl=ru`). По умолчанию используются три заданных запроса и глубина 20.

```bash
python3 google_news_parser.py
```

Результаты:

- `google_news_results.csv` — все поля, включая URL Google, тип результата,
  признак сюжетной группы, комментарий о релевантности и эвристическую
  тональность заголовка;
- `google_news_report.md` — сводная таблица и краткая аналитика.

Собственный текст публикаций не используется вместо поискового сниппета. Если
Google не отдает сниппет в карточке, записывается
`сниппет Google недоступен`. Точные дубли URL удаляются только внутри выдачи
одного запроса; разные публикации одного домена сохраняются.

Дополнительные запросы и файлы вывода можно задать явно:

```bash
python3 google_news_parser.py \
  --query "лобов вадим" \
  --limit 20 \
  --csv results.csv \
  --report report.md
```

Тесты:

```bash
python3 -m unittest -v
```
