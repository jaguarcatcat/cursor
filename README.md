# Парсер выдачи Google News

Скрипт снимает срез **Google News / Google Новости**, а не обычной органической выдачи Google. Для регулярного запуска есть HTML-панель в браузере: каждый сбор пишет документ в папку `otchet`.

## Регулярный запуск из папки

1. Откройте папку проекта.
2. Запустите файл:
   - Windows: `zapusk.bat`
   - Mac / Linux: `zapusk.sh`
3. В браузере откроется `index.html` (панель сбора).
4. Нажмите **Собрать отчёт**.

Не закрывайте окно сервера, пока работаете с панелью. Браузер сам по себе не может записать файл на диск, поэтому `zapusk.*` поднимает локальный сервер на `http://127.0.0.1:8765/`.

Документ появляется здесь:

```
otchet/
  2026-08-17_020815/     ← отдельная папка на каждый запуск
    otchet.html          ← документ для браузера / печати в PDF
    otchet.md
    dannye.json
    dannye.csv
  posledniy.html         ← копия последнего отчёта
```

Старые срезы не затираются: у каждого запуска своя папка с датой и временем.

## Что собирается

По каждому запросу: позиция, заголовок, СМИ, URL, домен, дата, сниппет (только из выдачи Google; иначе `сниппет Google недоступен`), тип карточки, комментарий о релевантности, отметка кластера.

По умолчанию:

- запросы: `лобов вадим университет синергия`, `лобов вадим синергия`, `лобов вадим`;
- регион/язык: `hl=ru`, `gl=RU`, `ceid=RU:ru`;
- глубина: первые 20 результатов.

## Запуск из терминала

```bash
python3 server.py
python3 google_news_parser.py
python3 -m unittest discover -s tests -v
```
