# Парсер выдачи Google Новости

Скрипт собирает первые 20 результатов для заданных запросов из
RU-локализованной новостной выдачи Google (`hl=ru`, `gl=RU`,
`ceid=RU:ru`), разрешает редиректы Google в URL публикаций и формирует:

- `google_news_report.md` — таблицу и краткую аналитику;
- `google_news_results.csv` — плоскую выгрузку;
- `google_news_results.json` — полные данные и метаданные проверки.

Запуск с тремя запросами из задания:

```bash
python3 google_news_parser.py
```

Произвольные запросы и каталог:

```bash
python3 google_news_parser.py \
  -q "лобов вадим" \
  -q "лобов вадим синергия" \
  --limit 20 \
  --output-dir output
```

Тесты:

```bash
python3 -m unittest -v
```

Скрипт использует только стандартную библиотеку Python. RSS Google News не
содержит фактический текстовый сниппет интерфейса, поэтому скрипт не выдаёт
заголовок за сниппет и записывает `сниппет Google недоступен`. Поля
`url_resolution_error` и `google_news_url` позволяют проверить случаи, когда
Google не разрешил получить прямой URL публикации.
