# Google News Parser

Парсер выдачи Google News (Google Новости) для мониторинга поисковых запросов.
**Финальный вывод — XLSX** с кликабельными URL на материалы.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python google_news_parser.py
```

Запросы загружаются из `queries.txt` (11 ключевых фраз). Прокси — из `proxies.txt`.

По умолчанию создаётся `results.xlsx` с листами:
- **Результаты** — полная таблица парсинга с кликабельными URL
- **Метаданные** — дата, регион, статистика
- **Покрытие запросов** — сколько результатов собрано по каждому запросу
- **Аналитика** — доминирующие СМИ, темы, тональность
- **Ограничения и рекомендации** — если не удалось собрать 20 результатов

### Прокси (обязательно для RU-выдачи)

Создайте файл `proxies.txt` (по одному прокси на строку):

```
http://user:pass@194.67.202.31:9606
http://user:pass@194.67.202.116:9377
```

```bash
python google_news_parser.py --proxies-file proxies.txt --output-xlsx results.xlsx
```

Прокси ротируются автоматически при ошибках.

### Параметры

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `--queries-file` | Файл со списком запросов | `queries.txt` |
| `--queries` | Запросы через CLI (перекрывает файл) | из `queries.txt` |
| `--max-results` | Макс. результатов на запрос | 20 |
| `--output-xlsx` | Имя XLSX (авто: `results_lvgnews_DDMMYY.xlsx`) | авто |
| `--output-dir` | Каталог для отчёта | `.` |

### Именование отчёта

- Первый сбор за день: `results_lvgnews_170826.xlsx` (дата DDMMYY по Москве)
- Повторный сбор в тот же день: `results_lvgnews_170826_0232.xlsx` (добавляется время `_HHMM` МСК)
| `--output-json` | Опциональный JSON-дамп | — |
| `--proxies-file` | Файл со списком прокси | `proxies.txt` |
| `--proxy` | Один прокси (дополнительно к файлу) | — |
| `--no-decode-urls` | Не раскодировать Google URL | — |

### Пример с прокси

```bash
export GNEWS_PROXY="http://user:pass@ru-proxy.example:8080"
python google_news_parser.py --output-xlsx output/results.xlsx
```

## Что собирает

- Позиция, заголовок, СМИ, **кликабельный URL материала**, дата, домен
- Тип результата, релевантность, маркировка кластеров Google News
- Сниппет (если Google отображает; иначе — «сниппет Google недоступен»)
- Источник данных (HTML / RSS)

## Ограничения глубины 20

1. **Узкий запрос** может иметь <20 публикаций в Google News (например, 15 — это предел выдачи, а не ошибка парсера).
2. **HTML-выдача** подгружает карточки через JavaScript; для 2-й «страницы» нужен Playwright/Selenium или RU-прокси.
3. **RSS** используется как дополнение, когда HTML не покрывает запрошенную глубину.
4. Google URL автоматически декодируются в прямые ссылки издателя через `googlenewsdecoder`.

## Параметры поиска

- Регион: Россия (`gl=RU`, `ceid=RU:ru`)
- Язык: русский (`hl=ru`)
- Источник: веб-выдача Google News + RSS (дополнение)
