# Google News parser

Скрипт собирает первые результаты поискового RSS Google News с российской
локализацией (`hl=ru`, `gl=RU`, `ceid=RU:ru`), сохраняет порядок выдачи и
декодирует ссылки Google в URL публикаций.

```bash
python3 google_news_parser.py
```

По умолчанию выполняются запросы:

- `лобов вадим университет синергия`
- `лобов вадим синергия`
- `лобов вадим`

Результаты записываются в `output/report.md`, `output/results.csv` и
`output/results.json`. Глубину и запросы можно изменить:

```bash
python3 google_news_parser.py \
  --query "лобов вадим" \
  --limit 20 \
  --output-dir output
```

`--no-resolve` отключает декодирование издательских URL и ускоряет проверку.
В этом режиме в поле URL остаются ссылки Google News.

## Ограничения данных

- RSS — официально доступный срез новостной выдачи, но его ранжирование может
  отличаться от персонализированного браузерного интерфейса.
- Google иногда возвращает меньше заданного лимита.
- RSS-описание часто содержит только заголовок и источник. Скрипт не выдаёт их
  за сниппет и записывает `сниппет Google недоступен`.
- `grouped_story=true` ставится только когда RSS-описание содержит несколько
  ссылок; неявные группировки интерфейса RSS не раскрывает.
- Тональность, тема и релевантность — прозрачные словарные эвристики, а не
  редакционная оценка.
