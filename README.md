# Google News Parser (RU / Russian)

Скрипт для сбора, декодирования прямых ссылок, дедупликации и аналитики новостной выдачи Google News (Google Новости) по поисковым запросам в российском регионе (`hl=ru`, `gl=RU`, `ceid=RU:ru`).

## Возможности

- **Целевая новостная выдача Google News**: использование официального новостного фида и структуры Google Новости для точной фиксации позиций и структуры выдачи.
- **Декодирование защищенных редиректов Google News**: автоматическое преобразование промежуточных ссылок `news.google.com/rss/articles/...` в прямые канонические URL на сайтах СМИ с помощью `googlenewsdecoder` и fallback HTTP-трассировки.
- **Строгая обработка сниппетов**: если в структуре Google News отсутствует текстовый сниппет, выводится `«сниппет Google недоступен»` без домысливания контента.
- **Дедупликация**: фильтрация точных дублей URL внутри каждого поискового запроса с сохранением уникальных публикаций одного и того же СМИ.
- **Определение метаданных**: определение типа результата (интервью, пресс-релиз, расследование, досье, блог, статья), тональности (позитивная, нейтральная, негативная), оценка релевантности запросу.
- **Экспорт данных**: сохранение результатов в JSON, CSV и Markdown форматах.
- **Аналитический модуль**: расчет доминирующих СМИ, частотных доменов, тематических интентов, тональности и ключевых источников влияния.

## Установка и запуск

```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск парсера для стандартных запросов
python3 google_news_parser.py

# Запуск парсера с кастомными запросами и глубиной
python3 google_news_parser.py --queries "лобов вадим" "лобов вадим синергия" --limit 20

# Запуск тестов
python3 -m pytest tests/ -v
```

## Структура проекта

- `google_news_parser.py` — основной исполняемый скрипт парсера и аналитики.
- `requirements.txt` — зависимости проекта (`requests`, `beautifulsoup4`, `googlenewsdecoder`, `tabulate`, `pytest`).
- `tests/test_parser.py` — набор модульных и интеграционных тестов.
- `results/` — директория с выгрузками (`google_news_results.json`, `google_news_results.csv`, `google_news_table.md`).
